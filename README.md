# 🐶 120 Dog Breed Classification

A Computer Vision project developed as part of an AI Bootcamp, focused on classifying images into **120 different dog breeds** using Deep Learning.

The project was also presented in a live webinar on YouTube as part of the bootcamp.

## 🛠️ Technologies & Methods

- **Python & TensorFlow/Keras**
- **MobileNetV2** – Transfer Learning with ImageNet weights
- **Keras Tuner** – Hyperparameter optimization using Hyperband
- **Data Augmentation** – Random flipping, rotation, and zoom
- **tf.data** – Efficient data loading and preprocessing
- **OpenCV & NumPy** – Image processing

## 🎯 Project Highlights

- Built a multi-class image classification pipeline for 120 dog breeds.
- Applied transfer learning using a pretrained MobileNetV2 backbone.
- Optimized model hyperparameters with Keras Tuner.
- Implemented custom callbacks for learning rate reduction and early stopping.
- Generated predictions and Kaggle competition submission files.
